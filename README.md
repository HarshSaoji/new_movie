
# 🎬 BookSmart

**BookSmart** is a modern, high-performance frontend template built with **Vite**, **TypeScript**, and **Tailwind CSS**. It is designed to help you build clean, scalable, and fast web applications with best development practices.

---

## 🚀 Features

- ⚡ **Vite** for ultra-fast development and builds  
- 🧪 **TypeScript** for strong typing and clean code  
- 🎨 **Tailwind CSS** for utility-first styling  
- 🧹 **ESLint** integrated for consistent code formatting  
- 🛠 **PostCSS** support  
- 📁 Scalable and clean folder structure  

---

## 📦 Getting Started

### Prerequisites
- Node.js (v14+ recommended)
- npm / yarn / pnpm

### Installation

```bash
git clone https://github.com/gaurav1Nn/new_movie.git
cd new_movie
npm install
````

### Start Development

```bash
npm run dev
```

### Create Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run serve
```
